# MirrorCast Pre-Built Releases

Official production release binaries for MirrorCast are published on the [GitHub Releases](https://github.com/0xSHARON/mirrorcast/releases) page.

### Available Downloads
- **Android APK**: `mirrorcast.apk` — Complete standalone Android application with hardware H.264 streaming, system audio capture, and QR scanner.
- **Windows Receiver**: `mirrorcast-windows-x64.zip` — Portable 64-bit Windows receiver application featuring DirectX hardware acceleration, connection confirmation modal, and interactive settings.
