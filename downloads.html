CLI Installation

Automated ADB Sideload & Tethering

If you have Android Debug Bridge (ADB) installed, install and connect in two terminal commands.

powershell / bash
# 1. Install APK on connected device
$ adb install -r mirrorcast.apk
# 2. Setup zero-latency USB reverse tunneling (optional for USB tethering)
$ adb reverse tcp:8080 tcp:8080
# 3. Launch the sender app directly from terminal
$ adb shell monkey -p com.mirrorcast 1

Prerequisites

Hardware & Operating System Requirements

Windows Host (Receiver)

  • • OS: Windows 10 (Build 1809+) or Windows 11 (64-bit)
  • • Processor: Dual-Core 1.8 GHz or faster (x86_64)
  • • Graphics: Direct3D 11 compatible GPU (Intel HD 4000+, NVIDIA Kepler+, AMD GCN+)
  • • RAM: 128 MB available memory
  • • Firewall: Allow incoming TCP/UDP on port 8080 and port 5353 (Local Subnet only)

Android Device (Sender)

  • • OS: Android 5.0 (API 21) or higher
  • • Audio Loopback: Android 10+ (API 29+) required for internal audio forwarding
  • • Hardware Encoder: OMX or C2 H.264 hardware encoder (standard on 99.8% of devices)
  • • Connection: 5 GHz Wi-Fi router (for wireless) or USB 2.0/3.0 cable with USB Debugging enabled
